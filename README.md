# LossProof

Сайт приложения LossProof для учёта личных финансов (в разработке, на
запуске будет бесплатным). Статический сайт: обычные HTML/CSS/JS, без
сборки. Задача сайта — быть полезным уже сейчас (бесплатные калькуляторы
приводят людей из поиска) и рассказывать о приложении, пока оно готовится.

Сайт продвигает только собственное приложение: партнёрских и реферальных
ссылок нет, чужие финансовые сервисы не рекламируются, советов по
инвестициям нет.

## История

- Вместе с разделами убраны их автоматизации: ночное обновление тарифов
  обменников (`update-tariffs.yml`) и еженедельная проверка компаний
  (`compliance-check.yml`).
- Старые адреса (`/calculator/`, `/exchanges/`, `/payout/…`, `/en/…` и
  другие) перенаправляются на главную — правило `redirects` в
  `vercel.json`; `/app/` ведёт на блок о приложении (`/#app`).
- В тот же день у LossProof появились логотип «Печать» и новые цвета:
  белый и изумрудный вместо тёмного «Графита» с голубым — на сайте, в
  приложении и в Telegram-канале.

## Запуск локально

Node.js не нужен: в `scripts/serve.ps1` лежит небольшой статический сервер
на PowerShell.

```powershell
powershell -ExecutionPolicy Bypass -File scripts\serve.ps1
```

Затем откройте http://localhost:8080/. Через `file://` страницы не
откроются: пути от корня сайта (`/assets/…`), как после публикации.

## Публикация

Vercel публикует сайт автоматически при каждом пуше в `main` (сборки нет,
раздаётся корень репозитория). Служебные файлы — `*.md`, `scripts/`,
`.github/`, `.claude/` — не публикуются (`.vercelignore`).

## Структура

- `index.html` — главная:
  - калькулятор «Сколько можно тратить в день до зарплаты»;
  - блок «Скоро: ещё калькуляторы»;
  - блок о приложении с макетом экрана и десятью возможностями;
  - «Спокойно за данные», вопросы, призыв подписаться на Telegram-канал
    https://t.me/LossProof1. Ссылка стоит в четырёх местах: шапка, первый
    экран, призыв подписаться, подвал.
- `404.html` — страница «Такой страницы нет». Vercel отдаёт её сам на
  любой несуществующий адрес.
- `assets/css/site.css` — все стили. Светлая тема «Изумруд», как в самом
  приложении: белый фон, изумрудный `#0b5d46` — цвет бренда (кнопки,
  цифры, логотип), мятные подложки `#e6f2ec` и `#f3f8f5`, кирпичный
  `#c2501a` только для «не хватает», шрифт Onest.
- `assets/js/spend.js` — калькулятор. Считает в браузере и никуда ничего не
  отправляет.
- `assets/js/faq.js` — на телефоне открыт только первый ответ в «Вопросах».
- `assets/fonts/` — Onest (переменный, 4 набора символов: кириллица и
  латиница с расширениями), лицензия OFL рядом. Файлы взяты из пакета
  `@fontsource-variable/onest` 5.3.1.
- `assets/icons/` — значки вкладки и главного экрана: логотип «Печать»
  (белая монета с гуртом и буквой L на изумрудной плитке). Тот же знак —
  в приложении и на аватаре Telegram-канала. В самих страницах знак
  встроен в разметку как SVG (класс `.seal`, цвет — через `color`), рядом
  надпись LOSSPROOF (`.wordmark`).

### Как считает калькулятор

`(остаток на карте − обязательные платежи до зарплаты) ÷ дни до зарплаты`,
с округлением вниз до рубля: лучше запас, чем не дотянуть. Это упрощённая
версия «Можно тратить сегодня» из приложения, где вместо остатка на карте
берётся бюджет месяца. Если обязательные платежи больше остатка,
калькулятор показывает, сколько не хватает. Числа вводятся как угодно:
«42000», «42 000», «42 000,50». После ввода поле само разбивает сумму на
разряды.

### Мобильная версия

Одна страница на все размеры (`@media` в `site.css`):
- до 1100 px первый экран в одну колонку: текст → калькулятор → кнопки;
- до 900 px в шапке остаётся только кнопка канала;
- до 600 px — телефонная раскладка:
  - короткие подписи — пары классов `hide-sm` / `show-sm` в разметке;
  - компактные карточки «Скоро»;
  - раскрывающиеся вопросы (`<details>`).

## Безопасность

- `vercel.json` задаёт заголовки. Политика CSP разрешает только свой домен:
  никаких встроенных скриптов и стилей, сторонних шрифтов, счётчиков и
  запросов к чужим сервисам. Новый внешний скрипт или запрос придётся
  осознанно добавить в CSP.
- `scripts/check-links.sh` + `scripts/allowed-domains.txt` +
  `.github/workflows/check-links.yml` падают, если в коде появится адрес с
  домена вне списка, ссылка не по https, «маскировка» домена через `@`, а
  также `eval`, `new Function` или `document.write`. Проверка запускается на
  каждый пуш и раз в сутки. Сейчас в списке только `t.me` (наш канал) и
  технические пространства имён.

## Что нужно доделать

- **Шрифт надписи LOSSPROOF.** Задуман PT Serif (лицензия OFL), но на
  сайте его пока нет — берётся системный шрифт с засечками (Georgia на
  Windows, iPhone и Mac). Чтобы надпись везде была одинаковой, положите
  PT Serif Bold в `assets/fonts/` и подключите через `@font-face`.
- **Калькуляторы из блока «Скоро»:** досрочное погашение кредита, налог
  самозанятого и ИП, подушка безопасности и цель. Каждому — своя страница
  для поиска. Когда калькулятор готов, карточка «Скоро» становится ссылкой.
- **Домен.** Когда он будет куплен, подставьте его вместо `example.com` в
  `sitemap.xml`, сделайте `Sitemap:` в `robots.txt` и `canonical`
  абсолютными.
- **Картинка для соцсетей** (`og:image`, 1200×630) — пока нет.

## Намеренно исключено

- **Реклама сторонних финансовых сервисов, партнёрские и реферальные
  ссылки.** Реклама иностранных криптобирж для аудитории из РФ закрыта
  законом «О рекламе» (ст. 7 п. 7, ст. 29.2), а с 01.07.2027 ст. 30
  закона № 282-ФЗ запрещает информировать о способах сделок в обход
  организаторов обращения. Не возвращать без нового юридического разбора.
- **Яндекс Метрика и любые счётчики.** С 01.09.2025 для cookie аналитики
  нужны согласие посетителя и политика обработки персональных данных
  (152-ФЗ). Вернуть можно только вместе с баннером согласия и страницей
  политики; прежний файл `assets/js/metrika.js` — в истории git (коммит
  34e44fa). Домены счётчика нужно будет добавить в CSP (`vercel.json`) и в
  `scripts/allowed-domains.txt`.
- **Google Fonts и другие внешние шрифты.** Шрифт лежит на сайте: так
  браузер посетителя не передаёт его IP третьим лицам.
- **Формы с личными данными** (почта, телефон для листа ожидания). Новости
  идут через Telegram-канал, поэтому сайт персональных данных не собирает.
